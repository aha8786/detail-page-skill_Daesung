# block_option_02

- 역할 태그: option
- 출처 형식: 상품 판매형 (신선 수산물)
- 한 줄 설명: "상품명 + 상품옵션" 제목과 대표 사진 1장 아래, 옵션마다 [번호 배지 | 옵션명·수량 | 총 내용량]을 한 줄 카드로 쌓아 중량별로 한눈에 비교하게 한 옵션 블록
- **사진 사용 규칙 (사용자 지정, 2026-10-13)**: 가격 옵션이 **여러 개**이면 대표 사진을 쓰지 않는다. 제목 바로 아래에 옵션 카드를 이어 붙인다. 가격 옵션이 1개일 때만 대표 사진을 쓴다

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│        [상품명 작은 제목]        │  ← 검정, 중간 굵기
│        [상품옵션 큰 제목]        │  ← 빨강, 아주 굵게
│                              │
│  ┌──────────────────────────┐  │
│  │    [대표 사진: 상품 실물]     │  │  ← 좌우 여백 약 20px
│  └──────────────────────────┘  │     ※ 가격 옵션이 여러 개면 이 사진 칸을 빼고
│                              │       제목 아래 약 40px에서 바로 카드 시작
│                              │
│  ╭──────────────────────────╮  │
│  │┌──┐ [옵션명]      [총 내용량]│  │  ← 연회색 둥근 카드
│  ││ 1│ [수량 범위]     [중량]  │  │     왼쪽 빨강 사각 배지 (번호+"옵션")
│  │└──┘                      │  │     오른쪽 중량은 빨강 크게
│  ╰──────────────────────────╯  │
│  ╭──────────────────────────╮  │
│  │┌──┐ 옵션 2 …               │  │  ← 옵션 수만큼 반복
│  ╰──────────────────────────╯  │
│  ╭──────────────────────────╮  │
│  │┌──┐ 옵션 3 …               │  │
│  ╰──────────────────────────╯  │
│                  [원산지 표기]   │  ← 오른쪽 정렬, 작은 글씨
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {상품명} | 텍스트 | 8~12자 | 작은 제목, 검정 |
| {블록제목} | 텍스트 | 4~6자 | "상품옵션" 같은 섹션명. 빨강, 가장 큰 글씨 |
| {대표사진} | 이미지 | 약 570 x 400px | 상품 실물이 가득 찬 컷 (용기에 담긴 모습 등). **가격 옵션이 여러 개면 쓰지 않음** |
| {번호N} | 배지 | 숫자 1자 + "옵션" | 빨강 사각 배지(약 64 x 64px, 모서리 살짝 둥글게), 흰 글씨 |
| {옵션명N} | 텍스트 | 5~8자 | 빨강, 굵게 |
| {수량N} | 텍스트 | 6~10자 | 마릿수·개수 범위. 회색 작은 글씨 |
| {내용량라벨} | 텍스트 | 4~5자 | "총 내용량" 등. 작은 검정 |
| {중량N} | 텍스트 | 2~5자 | 빨강, 아주 굵게, 크게 |
| {원산지} | 텍스트 | 10~20자 | 오른쪽 정렬 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경, 옵션 카드는 연회색(#f2f2f2 내외) 둥근 모서리(약 6px) / 빨강(#e0201b 내외) 하나만 포인트로 사용
- 폰트 크기 위계: 블록제목 약 48px (아주 굵게) / 상품명 약 26px / 중량 약 34px (아주 굵게) / 옵션명 약 26px (굵게) / 수량·라벨 약 18px
- 여백, 정렬, 강조 방식: 제목 가운데 정렬. 카드 안은 왼쪽 배지 → 가운데 옵션명(왼쪽 정렬) → 오른쪽 중량(오른쪽 정렬) 3단. 카드 높이 약 110px, 카드 사이 약 20px, 좌우 여백 약 30px
- 비교의 핵심(중량)을 오른쪽 끝에 크게 둬서 옵션끼리 숫자만 훑어도 차이가 보이게 함

## 사용 팁
- 잘 맞는 상품: 같은 상품을 **중량·수량만 다르게** 파는 경우 (활어·갑각류 kg별, 과일 kg별, 과메기 마릿수별)
- 구성이 옵션마다 크게 다르면 block_option_01(옵션별 구성 목록)이 더 맞고, 중량만 다르면 이 블록이 더 간결하다
- 옵션명·수량·중량·원산지는 모두 사실 정보다. 사용자가 준 내용만 쓰고, 없으면 [확인 필요]로 표시한다
- 가격 옵션이 여러 개면 대표 사진을 넣지 않는다 (사용자 지정). 실물은 앞의 hero·detail 블록 사진으로 보여준다
- 가격 옵션이 1개라서 대표 사진을 쓸 때는 실물 컷 1장이면 충분하다. 사진 아래 카드가 바로 이어지므로 사진 위에 글자를 올리지 않는다
