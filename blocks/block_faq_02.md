# block_faq_02

- 역할 태그: faq
- **사용 범위: 꽃게 전용** (꽃게의 특성에서 생기는 질문을 다루므로 꽃게 상품에만 사용한다. 다른 상품에는 추천하거나 배치하지 않는다)
- 출처 형식: 상품 판매형 (신선 수산물, 꽃게)
- 한 줄 설명: 연회색 배경 위에 "Q. 질문" 굵은 제목과 흰 둥근 카드 답변을 5개 쌓은, 사진 없는 꽃게 특성 Q&A 목록

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {질문N} | 텍스트 | "Q. " + 10~16자 | 고객 말투 그대로 ("~해요", "~했어요"). 아주 굵게, 검정 |
| {답변N} | 텍스트 (흰 카드) | 2~5줄, 줄당 28자 내외 | 원인 → 괜찮은지 → 어떻게 하면 되는지 순서 |

## 스타일
- 배경색 / 포인트 컬러: 블록 전체 연회색(#f2f2f2 내외), 답변 카드 흰색 / 포인트 컬러 없음 (검정과 회색만)
- 폰트 크기 위계: 질문 약 30px (아주 굵게) / 답변 약 18~19px (보통), 줄간격 약 1.7
- 여백, 정렬, 강조 방식: 전부 왼쪽 정렬. 좌우 여백 약 24px, 질문과 카드 사이 약 14px, 문항 사이 약 40px. 카드 모서리 약 12px, 안쪽 여백 약 24px. 강조 없이 담백하게
- 사진 없음. 문항 수에 맞게 늘리거나 줄인다 (3~6개 적당)

## 사용 팁
- **꽃게 상품 전용.** 다른 상품의 상세페이지에서는 B-4 블록 추천·선택 목록에 넣지 않는다
- 다룰 질문 예시 (꽃게 특성): 그물이 달려 옴, 다리가 떨어짐, 배 부분이 검게 보임, 내장 색이 다름, 도착 시 움직이지 않음, 철(암·수게 제철) 차이 등. **실제로 사용자가 준 질문과 답만 쓴다**
- block_faq_01(사진으로 보여주는 상황 Q&A)과 함께 쓸 때는 faq_01에서 사진이 필요한 상황 1~2개를 크게 다루고, 나머지 자잘한 특성 질문을 이 블록에 모은다. 같은 질문을 두 블록에 겹쳐 쓰지 않는다
- 답변 속 수치(살 비율 등), 원인, 처리 방법은 사실 정보다. 사용자가 준 내용만 쓰고 없으면 [확인 필요]로 표시한다
- 준법 주의: "드셔도 문제없다", "신선도에는 이상이 없다" 같은 안전 단정은 근거가 있을 때만 쓰고, 가능하면 "세척 후 조리하시면 됩니다"처럼 행동 안내로 쓴다
