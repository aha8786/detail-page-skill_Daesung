# block_hero_01

- 역할 태그: hero
- 출처 형식: 상품 판매형 (수산 가공식품)
- 한 줄 설명: 말풍선 안의 공감 한 줄과 2줄 대형 헤드라인 아래에, 손으로 상품을 들어 보여주는 클로즈업 사진을 크게 깐 첫 화면

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│   ┌────────────────────────┐   │
│   │ [말풍선 서브문구 1줄]      │   │  ← 테두리 박스 + 오른쪽 아래 꼬리
│   └──────────────────────╲─┘   │
│                              │
│     [헤드라인 1줄: 맛·특징]     │  ← 포인트 컬러
│     [헤드라인 2줄: 식감+상품명]  │  ← 진한 검정
│                              │
├──────────────────────────────┤
│                              │
│                              │
│   [손으로 상품을 들어 보여주는     │
│     클로즈업 사진, 화면 꽉 채움]   │
│                              │
│                              │
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {말풍선문구} | 텍스트 (테두리 말풍선) | 12~16자 | 계절·상황 공감형. 예: "[계절/상황]이면 생각나는 맛" 방향 |
| {헤드라인1} | 텍스트 | 8~10자 | 맛·특징 한 가지. 포인트 컬러, 느낌표로 끝맺음 |
| {헤드라인2} | 텍스트 | 8~10자 | "식감 형용사 + 상품명" 구조. 가장 진한 색 |
| {메인사진} | 이미지 | 610 x 약 520~600px | 손으로 상품을 집어 들어 결·윤기·두께가 보이는 클로즈업. 배경에 포장/구성이 살짝 보이면 좋음 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경 / 헤드라인 1줄은 상품색과 어울리는 진한 갈색·적갈색 계열, 2줄은 거의 검정(#222 내외)
- 폰트 크기 위계: 헤드라인 약 52~56px (아주 두꺼운 고딕, 자간 좁게) / 말풍선 약 28~30px (보통 굵기) / 본문 없음
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 상단 여백 약 40px, 말풍선과 헤드라인 사이 약 30px, 헤드라인 아래 약 40px 후 사진 시작. 사진은 좌우 여백 없이 가로 꽉 채움. 사진 위에는 글자를 올리지 않음
- 말풍선: 1.5~2px 진한 테두리, 직각 모서리, 오른쪽 아래에 사선 꼬리

## 사용 팁
- 잘 맞는 상품: 수산 건어물·가공품(과메기, 반건조 생선, 육포류), 손질 농수산물처럼 **결·윤기·두께가 맛을 설명해 주는 상품**
- 계절 상품(겨울 과메기, 제철 과일 등)은 말풍선에 계절 공감 문구를 넣으면 효과가 좋음
- 필요한 사진: 맨손 또는 장갑 낀 손으로 상품 1개를 들어 올린 클로즈업, 빛을 받아 윤기가 보이는 컷. 손 모양이 자연스럽고 손톱·피부 상태가 깔끔해야 함
- 헤드라인1(맛·특징)과 헤드라인2(식감)는 사진에서 실제로 보이는 특징(윤기 → 기름짐, 결 → 쫀득함)과 연결해서 쓴다
