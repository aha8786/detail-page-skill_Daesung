# block_hero_02

- 역할 태그: hero
- 출처 형식: 상품 판매형 (농산물, 산지 직송)
- 한 줄 설명: 산지 풍경 사진을 화면 전체에 깔고, 위쪽 하늘 여백에 헤드라인·서브카피를, 가운데에 손으로 든 대표 실물을, 오른쪽 아래에 원형 혜택 배지를 둔 정사각형 첫 화면

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준. 사진이 블록 전체 배경)
┌──────────────────────────────┐
│ (하늘 / 깨끗한 배경 영역)         │
│                              │
│    [헤드라인 1줄: 산지·지역]      │  ← 진한 자연색(짙은 초록 등), 아주 굵게
│    [헤드라인 2줄: 식감 + 상품 가치] │
│                              │
│    [서브카피 2줄: 수확·배송 약속]   │  ← 검정 계열, 보통 굵기
│                              │
│  ~~~~~ (산지 풍경 지평선) ~~~~~   │
│              ║               │
│         [손으로 든 대표 실물]       │  ← 가운데, 세로로 크게
│              ║               │
│              ║         ╭────╮│
│              ║         │ 🚚 ││  ← 원형 배지 (아이콘 + 2줄)
│              ║         │2줄 ││
│                        ╰────╯│
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {배경사진} | 이미지 (블록 전체) | 610 x 약 610px | 위쪽 40% 정도가 하늘처럼 깨끗해야 글자를 올릴 수 있음. 아래는 산지 현장(밭, 바다 등) |
| {헤드라인1} | 텍스트 | 7~10자 | 산지·지역 이름. 사진 위에 올리므로 배경과 대비되는 진한 색 |
| {헤드라인2} | 텍스트 | 10~13자 | 식감·맛 + 상품의 가치(선물, 맛 등) |
| {서브카피} | 텍스트 | 2줄, 줄당 15~18자 | 수확·배송 시점 약속 |
| {대표실물} | 이미지 일부 (배경 사진 안) | 세로로 약 400px | 손으로 상품 하나를 세워 든 모습. 배경 사진 안에 함께 찍혀 있어야 함 |
| {배지아이콘} | 아이콘 | 1개 | 배송 트럭 등 혜택을 나타내는 선 아이콘 |
| {배지문구} | 텍스트 | 2줄, 줄당 4~5자 | 핵심 혜택 (예: 수확·배송 방식) |

## 스타일
- 배경색 / 포인트 컬러: 배경은 사진 / 헤드라인은 사진 속 자연색과 어울리는 짙은 색(원본은 짙은 올리브 그린 #3E5A2A 내외), 서브카피 #222, 배지는 연한 베이지 원(#F3E6C4 내외)에 짙은 글씨. 다른 블록과 함께 쓰면 페이지 통일 컬러로 바꿈
- 폰트 크기 위계: 헤드라인 약 44~46px (아주 굵게) / 서브카피 약 22px / 배지 문구 약 18px (굵게)
- 여백, 정렬, 강조 방식: 헤드라인·서브카피 가운데 정렬. 위쪽 여백 약 70px, 헤드라인과 서브카피 사이 약 24px. 배지는 오른쪽 아래, 지름 약 160px, 가장자리에서 약 30px 안쪽. 글자에 그림자·외곽선 없이 깨끗한 하늘 위에 바로 올림

## 사용 팁
- 잘 맞는 상품: 산지 풍경이 상품 가치를 설명해 주는 농수산물 (산지 직송 농산물, 바다·갯벌 배경의 수산물, 과수원 과일)
- 이 블록은 **사진이 레이아웃을 결정**한다. 위쪽에 깨끗한 여백(하늘 등)이 있고, 산지 풍경 앞에서 상품을 든 세로 구도 사진이 있어야 쓸 수 있다. 하늘이 복잡하거나 없는 사진이면 글자를 올리지 말고 block_hero_01을 쓴다
- 헤드라인1의 산지 이름은 사진 속 풍경과 일치해야 한다 (바다 사진에 "강원도 산지" 같은 문구 금지)
- 배지 문구(당일 수확, 산지직송 등)와 서브카피의 수확·도착 약속은 사실 정보다. 사용자가 준 배송 조건만 쓰고, 없으면 배지를 빼거나 [확인 필요]로 표시한다
- 준법 주의: "내일 도착" 같은 도착 약속은 실제 배송 조건이 보장될 때만 쓴다. 아니면 "산지에서 바로 보내드려요"처럼 완화한다
