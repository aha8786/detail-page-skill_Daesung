# block_info_02

- 역할 태그: info (제품 상세정보 · 고지 사항)
- 출처 형식: 상품 판매형 (수산물)
- 한 줄 설명: "제품 상세정보" 제목 아래 "· 항목 : 값" 목록으로 상품 기본 정보를 정리하고, 가는 구분선 뒤 테두리 박스에 알레르기·교환·반품 고지 문구를 넣은 정보 블록
- **상품마다 내용이 달라지는 블록**: 아래 "제작 시 질문"을 반드시 거쳐 내용을 정한다

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {블록제목} | 텍스트 | "제품 상세정보" | 아주 굵게, 포인트 컬러 |
| {항목N} | "· 항목명 : 값" | 줄당 25자 이내, 4~7줄 | 항목명과 값 사이 " : ". 값이 길면 2줄로 |
| {고지문구} | 텍스트 (테두리 박스) | 3~4줄, 줄당 32자 내외 | 알레르기 주의, 교환·보상 기준, 반품 장소 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경 / 제목·구분선만 포인트 컬러(원본은 남색 #1F3C88 내외. 다른 블록과 함께 쓰면 페이지 통일 컬러로 바꿈), 목록 검정 #222, 박스 테두리 진회색 1px
- 폰트 크기 위계: 제목 약 38px (아주 굵게) / 목록 약 25px (보통) / 고지 문구 약 17px, 줄간격 1.5
- 여백, 정렬, 강조 방식: 전부 왼쪽 정렬, 좌우 여백 약 50px. 제목 아래 약 30px, 목록 줄 간격 약 14px, 목록 아래 약 30px에 구분선, 구분선 아래 약 40px에 박스. 박스 안쪽 여백 약 22px. 강조 없음 (정보 전달용)
- 사진 없음

## 제작 시 질문 (작업 B에서 이 블록을 고르면 기획안 작성 전에 반드시 묻는다)
앞 단계에서 받은 정보로 값을 **미리 채워서** 보여주고, 빈 칸과 추가 항목만 묻는다.

```text
[제품 상세정보 블록] 아래 내용으로 넣을까요? (빈 칸은 채워 주세요)
· 상품명 : [B-1에서 받은 상품명]
· 내용량 : [받은 중량·수량]
· 원산지 : [받은 원산지]
· 원재료명 및 함량 : [받은 값 또는 확인 필요]
· 보관방법 : 본문 참조
(· 알레르기 성분 : 본문 참조 — 항목을 추가할 때)
※ 택배·배송 안내는 이 블록에 넣지 않는다 (묻지도 않음)

A. 이대로 (빈 칸은 "제품 라벨 참고"로 표시)
B. 항목 추가 (추천 여부와 이유: 식품이면 소비기한, 식품유형, 생산자 및 소재지, 알레르기 성분을 함께 넣으면 상품정보제공고시와 맞추기 쉬움)
C. 값 수정
고지 문구: 기본값 그대로 / 수정 / 빼기
✏️ 직접 입력 / 추가 요청:
```

- 원재료 함량(예: "홍게 100%")처럼 수치가 들어가는 값은 사용자가 준 경우에만 쓴다. 없으면 "제품 라벨 참고" 또는 [확인 필요]로 둔다
- 보관방법·알레르기 성분 값은 항상 "본문 참조"로 쓴다 (사용자 지정). 택배 발송일·도착일·지연 발송 같은 택배 내용은 이 블록에 넣지 않는다 (사용자 지정)
- 고지 문구의 "알레르기 유발 제품" 문장은 실제로 알레르기 유발 성분(게, 새우, 대두, 밀, 우유, 땅콩 등)이 있는 상품에만 넣는다. 성분을 알면 "게 함유"처럼 구체적으로 쓴다

## 사용 팁
- 잘 맞는 상품: 모든 식품 (특히 수산물·가공식품). 페이지 맨 끝, 옵션 블록 다음에 두면 좋다
- 이 블록은 상품정보제공고시를 대신하지 않는다. 판매 플랫폼의 고시 입력란에는 따로 정확히 입력해야 한다
- 준법 주의: "최대한 빠른 시일 내에 섭취"처럼 기한이 불분명한 표현은 소비기한 정보가 따로 있을 때 함께 쓴다
