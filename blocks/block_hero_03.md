## 요소와 슬롯

## 스타일
- 배경색 / 포인트 컬러: 사진 아래는 흰색(#FFFFFF). 상품명 뒷부분만 선명한 노랑(#F5C200 내외). 노랑은 흰 배경에서 대비가 약하므로 **아주 굵게 + 큰 크기일 때만** 사용. 상품 색에 맞춰 바꿔도 됨 (예: 빨강 #E53935, 주황 #F08A00, 남색 #1E2A6E)
- 폰트 크기 위계: 상품명 약 64px (가장 굵게, 자간 좁게) / 서브문구 약 26px (보통) / 설명 약 27px (설명1~2·마무리는 굵게 600~700, 설명3~4는 보통 400 회색 #8A8A8A), 줄간격 1.45
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 사진 끝 → 서브문구 약 50px, 서브문구 → 상품명 약 6px(바짝 붙임), 상품명 → 설명 약 40px, 아래 여백 약 50px. 강조는 색(상품명)과 굵기·회색 대비(설명 줄)로만 하고 밑줄·박스·아이콘은 쓰지 않음

## 사용 팁
- 잘 맞는 상품: 겉모습만으로 먹음직스러움이 전해지는 농산물·수산물 (옥수수, 과일, 채소, 갑각류·조개처럼 무리 지어 찍기 좋은 것)
- 이 블록은 **사진에 글자를 올리지 않으므로** 라벨·복잡한 배경이 있는 사진도 위쪽에 쓸 수 있다. 대신 사진이 꽉 차 보여야 해서 여백 많은 제품컷·흰 배경 누끼컷에는 맞지 않는다 (그런 사진이면 block_hero_01)
- 필요한 사진: 같은 상품 여러 개를 빽빽하게 깔고, 그중 하나를 손질·단면 상태로 앞에 크게 둔 세로 클로즈업. 세로 비율이 610 x 740 이상 나오지 않으면 위아래를 잘라 맞춘다 (대표 실물이 잘리지 않게)
- 설명 1~2줄은 사진에 보이는 질감(알갱이, 윤기, 결)과 연결하고, 3~4줄 산지·재배 이야기는 사용자가 준 사실만 쓴다. 없으면 `[확인 필요: 산지]`로 두거나 해당 2줄을 뺀다
- 마무리 줄은 "한번 맛보면 잊을 수 없는 ○○!"처럼 맛을 단정하는 강한 카피를 그대로 써도 된다 (prompt.md 준법 필터 완화 기준). 단 "판매 1위", 질병·효능 표현은 넣지 않는다
