# block_point_01

- 역할 태그: point
- 출처 형식: 상품 판매형 (수산 가공식품)
- 한 줄 설명: "만드는 방식 → 그래서 생기는 맛"을 2줄 헤드라인으로 말하고, 그 과정을 보여주는 현장 사진 2장을 위아래로 이어 붙인 차별점 블록

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│                              │
│   [헤드라인 1줄: 방식·공정]      │  ← 빨강 포인트 컬러
│   [헤드라인 2줄: 결과·맛]        │  ← 진한 검정
│                              │
├──────────────────────────────┤
│                              │
│   [현장 사진 1: 공정 전경]       │  ← 가로 꽉 채움
│   (넓게, 규모감)               │
│                              │
├──────────────────────────────┤  ← 흰 간격 약 8px
│                              │
│   [현장 사진 2: 공정 근접]       │  ← 가로 꽉 채움
│   (반복 패턴, 디테일)           │
│                              │
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {헤드라인1} | 텍스트 | 8~11자 | 제조·재배·손질 방식 키워드. 빨강 포인트 컬러 |
| {헤드라인2} | 텍스트 | 8~11자 | 그 방식 덕분에 생기는 맛·품질. 진한 검정, 느낌표로 끝맺음 |
| {현장사진1} | 이미지 | 610 x 약 450px | 공정 전경 (건조장, 산지, 작업장 등). 규모와 환경이 보이게 |
| {현장사진2} | 이미지 | 610 x 약 470px | 같은 공정의 근접 컷. 상품이 줄지어 반복되는 패턴이면 좋음 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경 / 헤드라인 1줄 빨강(#e0201b 내외), 2줄 거의 검정(#222 내외)
- 폰트 크기 위계: 헤드라인 약 48~52px (아주 두꺼운 고딕, 두 줄 같은 크기) / 본문 없음
- 여백, 정렬, 강조 방식: 가운데 정렬. 상단 여백 약 40px, 헤드라인 아래 약 40px 후 사진 시작. 사진 2장은 좌우 여백 없이 꽉 채우고 사이에 흰 간격 약 8px. 사진 위에 글자를 올리지 않음

## 사용 팁
- 잘 맞는 상품: 만드는 방식이 맛을 결정하는 상품 (자연 건조 수산물, 발효·숙성 식품, 노지 재배 농산물, 산지 직송)
- 헤드라인1은 사진에 실제로 보이는 공정(예: 건조, 숙성, 수확)을 말하고, 헤드라인2는 그 공정이 주는 맛을 말한다. 사진에 없는 공정을 헤드라인에 쓰지 않는다
- 필요한 사진: 실제 생산 현장 사진 2장 (전경 1 + 근접 1). 하늘·자연광이 보이면 "자연 그대로" 인상이 강해짐
- 공정 방식(예: 특정 건조법, 산지)은 사실 정보이므로 사용자가 준 내용만 쓰고, 없으면 [확인 필요]로 표시한다
