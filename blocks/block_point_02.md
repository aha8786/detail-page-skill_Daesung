# block_point_02

- 역할 태그: point (핵심 약속 요약. 근거 자료가 있으면 trust 자리에도 사용 가능)
- 출처 형식: 상품 판매형 (수산물)
- 한 줄 설명: 밑줄 친 빨강 헤드라인으로 "약속"을 선언하고, 번호 목록 5줄마다 핵심 키워드를 노란 형광펜 박스로 강조한 사진 없는 텍스트 블록

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│                              │
│    [서브 헤드라인: 품질 수식어]    │  ← 검정, 보통~중간 굵기
│    [메인 헤드라인: 약속 선언]      │  ← 빨강, 아주 굵게
│    ━━━━━━━━━━━━━━━━━━━━━━━    │  ← 헤드라인 폭만큼 빨강 밑줄
│                              │
│  1. [설명 문구] [▓키워드▓]       │  ← 가운데 정렬
│  2. [설명 문구] [▓키워드▓]       │     키워드는 [ ] + 굵게 + 노란 배경
│  3. [설명 문구] [▓키워드▓]       │
│  4. [설명 문구] [▓키워드▓]       │
│  5. [설명 문구] [▓키워드▓]       │
│                              │
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {서브헤드라인} | 텍스트 | 12~16자 | 품질·산지 수식어. 검정 |
| {메인헤드라인} | 텍스트 | 10~13자 | "~를 약속할게요" 같은 선언형. 빨강, 아래 빨강 밑줄(약 3px) |
| {설명1~5} | 텍스트 | 각 8~12자 | 키워드를 꾸며주는 앞부분. 보통 굵기 |
| {키워드1~5} | 텍스트 (강조 박스) | 각 4~8자 | [ ]로 감싸고 굵게, 노란 배경(#ffe94d 내외) |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경 / 빨강(#e0201b 내외) 헤드라인·밑줄, 노랑 형광 박스, 본문 검정(#222)
- 폰트 크기 위계: 메인헤드라인 약 40px (아주 굵게) / 서브헤드라인 약 28px / 목록 약 26px, 키워드만 굵게
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 위아래 여백 약 60px, 헤드라인과 목록 사이 약 40px, 목록 줄 간격 약 22px. 강조는 빨강(헤드라인)과 노랑 박스(키워드) 두 가지만 사용
- 사진 없음. 사진 블록 사이에 넣어 쉬어 가는 정리 블록으로 쓰기 좋음

## 사용 팁
- 잘 맞는 상품: 산지·제철·신선도·포장·보상처럼 **약속할 항목이 여러 개인** 신선 농수산물
- 목록은 3~5줄이 적당하다. 사실 정보가 3개뿐이면 3줄로 줄이고 억지로 채우지 않는다
- 준법 주의: 원본의 "100% 국내산", "수율 80%", "100% 책임보상" 같은 수치·절대 표현은 사용자가 근거(원산지 증빙, 실제 보상 규정)를 준 경우에만 쓴다. 없으면 [확인 필요]로 표시하거나 "국내산", "보상 기준 안내" 등으로 완화한다
- 보상·AS 약속은 실제 교환·환불 규정과 문구가 일치해야 한다
