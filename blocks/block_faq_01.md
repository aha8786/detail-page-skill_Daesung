# block_faq_01

- 역할 태그: faq
- **사용 범위: 꽃게 전용** (꽃게 상품에만 사용한다. 다른 상품에는 추천하거나 배치하지 않는다)
- 출처 형식: 상품 판매형 (신선 수산물, 꽃게)
- 한 줄 설명: 받은 꽃게에서 고객이 놀랄 만한 상황(검은 물, 다리 떨어짐)을 질문형 헤드라인과 실물 사진으로 먼저 보여주고, 원인 설명 → 정상 기준 → 보상 기준 순으로 불안을 풀어주는 Q&A 블록

## 스타일
- 배경색 / 포인트 컬러: 상황1 흰 배경, 상황2 연회색(#f0f0f0 내외) 배경으로 구분 / 진한 빨강(#c8161d 내외) 띠·번호·강조, 본문 검정
- 폰트 크기 위계: 질문 헤드라인 약 40px (아주 굵게) / 상황 소제목 약 26px / 빨강 띠 답변 약 24px / 본문 약 20px / 정상 기준 약 24px (굵게)
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 빨강 띠는 좌우 여백 없이 가로 꽉 채움. 보상 기준 박스는 좌우 여백 약 50px, 얇은 테두리
- 상황 카드 1개당 [질문 → 사진 → 답 → 이유 → 기준] 순서를 지킨다. 상황 수에 맞게 카드를 늘리거나 줄인다

## 사용 팁
- **꽃게 상품 전용.** 다른 상품의 상세페이지에서는 B-4 블록 추천·선택 목록에 넣지 않는다
- 다룰 상황은 꽃게를 받고 고객이 실제로 문의하는 것(검은 물, 다리 떨어짐, 냄새, 색 변화 등)으로 고른다. 사용자가 준 상황만 쓴다
- 원인 설명, 정상 기준(예: 다리 몇 개 이상), 보상 기준은 모두 사실 정보다. 사용자가 준 기준만 쓰고, 없으면 [확인 필요: 다리 탈락 정상 기준], [확인 필요: 보상 조건]으로 표시한다
- 사진은 반드시 그 상황이 실제로 보이는 컷을 쓴다 (검은 물 질문 → 배 쪽을 보여주는 컷, 다리 질문 → 다리가 보이는 컷). 상황과 무관한 예쁜 컷을 쓰지 않는다
- 준법 주의: "섭취해도 무조건 안전" 같은 단정은 피하고 "세척 후 조리하시면 됩니다"처럼 행동 안내로 쓴다
- 참고 캡처 해상도가 낮아 색·크기는 대략값이다
