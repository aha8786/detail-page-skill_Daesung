# block_usage_01

- 역할 태그: usage (조리 후 플레이팅)
- 출처 형식: 사용자 지정 블록 (참고 페이지 분석 없이 사용자 요청으로 만듦)
- 한 줄 설명: 상단에 원형 아이콘 + "{상품명}를 더욱 더 / 맛있게 먹는 방법" 2줄 제목을 두고, 그 아래 조리·플레이팅 사진을 가로 610px에 맞춰 세로로 3장 이상 이어 붙여 "이렇게 먹는다"를 보여주는 블록
- 변경 기록: 2026-10-14 상단 제목 영역 추가 (사용자 요청, 참고 캡처 `스크린샷 2026-10-14 191341.png`)

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│          ( 원형 아이콘 )         │  ← 남색 원 + 흰 선 아이콘 (상품 모양)
│                              │
│     {상품명}를 더욱 더 (남색)     │  ← 제목 1줄
│     맛있게 먹는 방법 (검정·대형)   │  ← 제목 2줄, 블록에서 가장 큰 글씨
│                              │
│  ※ 연출 예시 안내 1줄 (작은 회색)   │  ← 구성품 아닌 재료가 보일 때만
│                              │
├──────────────────────────────┤
│                              │
│  [플레이팅 사진 1: 전체 상차림]   │  ← 가로 610px, 세로는 원본 비율
│                              │
├──────────────────────────────┤  ← 흰 간격 8px
│                              │
│  [플레이팅 사진 2: 접시 근접]     │
│                              │
├──────────────────────────────┤
│                              │
│  [플레이팅 사진 3: 한입·디테일]   │
│                              │
├──────────────────────────────┤
│  … 사진이 더 있으면 같은 방식으로   │  ← 최소 3장, 권장 3~5장
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 | 비고 |
|---|---|---|---|
| {아이콘} | 원형 배지 안 흰 선 아이콘 | 1개 | 판매 상품 모양 (새우·게·생선 등). 상품에 맞는 아이콘이 없으면 수저·접시 아이콘 |
| {제목1} | 텍스트 | "{상품명}를 더욱 더" (15자 내외) | 받침 있으면 "을", 없으면 "를" (예: 홍게를 / 과메기를 / 암꽃게를). 상품명이 길면 줄여 씀 |
| {제목2} | 텍스트 | "맛있게 먹는 방법" 고정 | 가장 큰 글씨 |
| {연출안내} | 텍스트 | "※ 플레이팅 사진은 연출 예시이며, 일부 재료는 구성에 포함되지 않습니다" | 제목 아래, 첫 사진 위. 사진에 구성품이 아닌 재료가 보일 때만 넣음 (사용자 지정, 2026-10-14) |
| {플레이팅사진1~N} | 이미지 | **최소 3장**, 권장 3~5장 | 가로 610px에 맞추고 세로는 원본 비율 그대로 (자르지 않음). 너무 긴 세로 사진(세로가 900px 넘음)만 위아래를 살짝 잘라 약 760px로 맞춤 |

## 스타일
- 배경색: 흰색
- 제목 영역 (가운데 정렬, 흰 배경)
  - 위 여백 약 60px, 제목과 첫 사진 사이 약 40px
  - 아이콘: 지름 약 84px 남색(#1E3A8A 계열) 원, 안에 흰색 선 아이콘. 아이콘과 제목 사이 약 20px
  - 제목1: 약 32px / 굵게(700) / 남색 (아이콘과 같은 색)
  - 제목2: 약 46px / 아주 굵게(800~900) / 검정(#111). 제목1보다 확실히 크게. 두 줄 사이 간격 좁게(약 6px)
  - 연출안내: 제목2 아래 약 16px, 약 15px / 보통 굵기 / 회색(#888). 넣으면 이 줄과 첫 사진 사이가 약 40px
- 사진 영역
  - 사진 사이 흰 간격 8px (block_point_01과 같은 간격으로 페이지 통일)
  - 마지막 사진 아래 여백 없음. 다음 블록과 바로 이어 붙임
  - 사진 위에 글자·스티커를 올리지 않음 (글자는 위 제목 영역에만)

## 사진 고르는 기준
1. **조리 후·플레이팅 사진만** 고른다
   - 고른다: 접시·그릇에 담은 완성 음식, 상차림, 밥 위에 올린 모습, 손으로 들거나 젓가락으로 집은 먹는 장면
   - 고르지 않는다: 생물·손질 전 원물, 산지·작업장 현장, 얼린 상태, 포장 박스, 다른 음식(예: 게장 상품에 꽃게탕 사진)
   - **구성품이 아닌 재료가 함께 있어도 괜찮다 (사용자 지정, 2026-10-13)**: 깻잎·김치·반찬·소스·술잔처럼 구성에 없는 재료가 함께 차려져 있어도, 주인공이 판매 상품이면 고른다. 구성품이 아닌 재료가 보인다는 이유만으로 빼지 않는다
   - 이때 이 블록 제목 아래(첫 사진 위)에 {연출안내} 한 줄을 넣는다 (옵션 블록은 쓰지 않으므로 여기에 둔다)
   - 그래도 빼는 경우: 주인공이 판매 상품이 아닌 다른 음식인 사진, 주류 등 상표·로고가 크게 보이는 사진, 다른 계정 워터마크가 있는 사진
2. 같은 상세페이지의 다른 블록에서 이미 쓴 사진은 되도록 다시 쓰지 않는다. 겹칠 수밖에 없으면 사용자에게 알린다
3. 배치 순서는 **멀리서 → 가까이**: 전체 상차림·접시 전체 → 접시 근접 → 한입·속살·디테일
4. 비슷한 구도의 사진이 여러 장이면 가장 선명한 1장만 쓴다 (같은 사진의 크롭본 중복 금지)
5. 품질이 `재촬영 권장`(흔들림, 어두움, 지저분한 배경)인 사진은 넣지 않는다

## 제작 시 질문 (작업 B에서 이 블록을 고르면 기획안 작성 전에 반드시 묻는다)
B-3 사진 분석 결과에서 위 기준에 맞는 사진을 골라 **배치안을 먼저 보여주고** 확인받는다.

```text
[조리 후 플레이팅 블록] 상단 제목과 사진을 이렇게 넣을까요?
제목: ([아이콘 종류]) "[상품명]를 더욱 더 / 맛있게 먹는 방법"
사진 순서:
1. [파일명] — [보이는 내용, 예: 접시에 담은 게장 전체]
2. [파일명] — [예: 알이 보이는 근접 컷]
3. [파일명] — [예: 손으로 든 한입 컷]
(제외한 플레이팅 사진: [파일명 — 이유])

A. 이대로 (추천 여부와 이유)
B. 사진 바꾸기 / 순서 바꾸기
C. 사진 추가 (최대 5장 권장)
✏️ 직접 입력 / 추가 요청:
```

- 기준에 맞는 사진이 **3장 미만**이면 억지로 채우지 않는다. "플레이팅 사진이 N장뿐입니다"라고 알리고 아래 중에서 고르게 한다
  ```text
  A. 플레이팅 사진 추가로 주기 (추천: 최소 3장이 이 블록의 기준)
  B. 있는 N장으로만 구성
  C. 이 블록 빼기
  ✏️ 직접 입력 / 추가 요청:
  ```

## 사용 팁
- 잘 맞는 상품: 조리·플레이팅 모습이 맛을 설명해 주는 식품 (게장, 회, 과메기 한 상, 밀키트, 반찬, 손질 수산물)
- 글은 상단 제목뿐이라 앞 블록(hero, point, detail)에서 맛을 말로 설명한 뒤에 두면 "말 → 증명" 흐름이 된다. 옵션·정보 블록 바로 앞이 좋다
- 사진의 주인공은 실제 판매 상품이어야 한다. 함께 차린 밥·반찬·곁들임 재료는 있어도 되고, 대신 이 블록 제목 아래에 {연출안내}가 들어갔는지 확인한다
