# block_point_03

- 역할 태그: point (산지·어획·선별 기준)
- 출처 형식: 상품 판매형 (과일·농산물)
- 한 줄 설명: "CHECK POINT + 큰 번호" 라벨로 차별점을 번호 매겨 소개하고, 산지 현장 사진 3장(위 2장 나란히 + 아래 1장 넓게)으로 선별 과정을 보여주는 시리즈형 차별점 블록

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│        · CHECK POINT ·        │  ← 작은 영문 라벨, 포인트 컬러, 양옆 점
│             01               │  ← 큰 번호, 포인트 컬러
│     [헤드라인 1줄: 방식·과정]     │  ← 검정
│     [헤드라인 2줄: 결과·상품명]    │  ← 포인트 컬러, 아주 굵게
│                              │
├───────────────┬──────────────┤
│               │              │
│  [현장 사진 A]  │ [현장 사진 B]  │  ← 2장 나란히, 사이 간격 약 6px
│  (손으로 고르는  │ (상품 근접)    │
│   모습)        │              │
├───────────────┴──────────────┤  ← 간격 약 6px
│                              │
│   [현장 사진 C: 사람이 직접       │  ← 가로 꽉 채움
│    확인하는 장면, 넓게]          │
│                              │
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {라벨} | 텍스트 | "CHECK POINT" 고정 | 작은 영문 대문자, 양옆 점 장식 |
| {번호} | 텍스트 | 2자 (01, 02 …) | 큰 숫자. 같은 블록을 연달아 쓰면 01 → 02 → 03 |
| {헤드라인1} | 텍스트 | 9~12자 | 산지·어획·선별 방식. 검정, 굵게 |
| {헤드라인2} | 텍스트 | 8~11자 | 그 결과 + 상품명. 포인트 컬러, 아주 굵게 |
| {현장사진A} | 이미지 | 302 x 약 300px | 손으로 상품을 고르거나 들고 있는 현장 컷 |
| {현장사진B} | 이미지 | 302 x 약 300px | 같은 현장의 상품 근접 컷 |
| {현장사진C} | 이미지 | 610 x 약 420px | 사람이 직접 확인·선별하는 넓은 컷 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경 / 포인트 컬러 하나(원본은 주황 #F47A20 내외. 다른 블록과 함께 쓰면 페이지 통일 컬러로 바꿈), 검정 #222
- 폰트 크기 위계: 번호 약 52px (아주 굵게) / 헤드라인 약 36~38px (2줄째가 더 굵게) / 라벨 약 15px (굵게, 자간 넓게)
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 상단 여백 약 50px, 라벨·번호·헤드라인을 촘촘히 붙이고 헤드라인 아래 약 36px 후 사진. 사진 3장 사이 간격 약 6px 흰색. 사진은 좌우 여백 없이 꽉 채움. 사진 위에 글자를 올리지 않음

## 사용 팁
- 잘 맞는 상품: 산지·어획·선별 기준이 여러 개라 **번호를 매겨 차례로 보여줄 수 있는** 농수산물 (과일 선별, 꽃게·생선 어획, 산지 수확)
- 같은 블록을 01, 02, 03으로 이어 쓰면 "체크포인트 시리즈"가 된다. 번호마다 다른 기준 하나만 다룬다
- 사진 3장은 모두 그 번호의 기준과 직접 연결돼야 한다 (예: "직접 선별" → 손으로 고르는 컷, "산지" → 현장 컷). 기준과 무관한 예쁜 상품 컷으로 채우지 않는다
- 산지, 어획 방식, 선별 기준은 사실 정보다. 사용자가 준 내용만 쓰고, 없으면 [확인 필요]로 표시한다
- 준법 주의: "철저한", "오리지널" 같은 수식어는 근거가 있을 때만 쓴다
- 참고 캡처 해상도가 낮아 색·크기는 대략값이다
