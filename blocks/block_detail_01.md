# block_detail_01

- 역할 태그: detail (구성품 소개. 세트 상품이면 option 자리에도 사용 가능)
- 출처 형식: 상품 판매형 (수산 가공식품 세트)
- 한 줄 설명: 2줄 헤드라인과 강조가 섞인 4줄 설명 아래, 구성품 전체를 위에서 내려다본 한 장의 플랫레이 사진으로 "이렇게 받는다"를 보여주는 구성 블록

## 레이아웃 구조
(ASCII 와이어프레임, 가로 610px 기준)
┌──────────────────────────────┐
│                              │
│   [헤드라인 1줄: 상품 + 역할]    │  ← 진한 검정
│   [헤드라인 2줄: 핵심 약속]      │  ← 빨강 포인트 컬러
│                              │
│   [설명 1줄: 구성품 나열 시작]    │  ← 보통 굵기
│   [설명 2줄: **핵심 구성품 강조**] │  ← 굵게
│   [설명 3줄: 어우러짐 설명]      │  ← 보통 굵기
│   [설명 4줄: 결론 한마디]        │  ← 빨강 + 굵게
│                              │
├──────────────────────────────┤
│                              │
│   [구성품 전체 플랫레이 사진]     │  ← 위에서 내려다본 컷, 가로 꽉 채움
│   (밝은 대리석·흰 배경에           │
│    구성품을 격자처럼 배치)         │
│                              │
└──────────────────────────────┘

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {헤드라인1} | 텍스트 | 9~11자 | "상품명 + 무엇을 살리는/돕는" 구조. 진한 검정 |
| {헤드라인2} | 텍스트 | 8~10자 | 구성의 핵심 약속. 빨강, 느낌표로 끝맺음 |
| {설명1} | 텍스트 | 12~16자 | 함께 들어 있는 구성품 나열 |
| {설명2} | 텍스트 (굵게) | 12~16자 | 가장 자랑할 구성품 1개를 굵게 강조 |
| {설명3} | 텍스트 | 16~20자 | 구성품이 본품과 어떻게 어우러지는지 |
| {설명4} | 텍스트 (빨강·굵게) | 12~16자 | 결론 한 문장 |
| {구성사진} | 이미지 | 610 x 약 500px | 구성품 전체를 위에서 찍은 플랫레이. 하나도 빠짐없이, 겹치지 않게 |

## 스타일
- 배경색 / 포인트 컬러: 텍스트 영역 흰 배경, 사진 영역 밝은 회색 대리석 / 빨강(#e0201b 내외)과 진한 검정(#222 내외)
- 폰트 크기 위계: 헤드라인 약 46~50px (아주 두꺼운 고딕) / 설명 약 26~28px (보통, 강조 줄만 굵게) / 줄간격 넉넉하게(약 1.5)
- 여백, 정렬, 강조 방식: 전부 가운데 정렬. 헤드라인과 설명 사이 약 40px, 설명 아래 약 40px 후 사진. 강조는 굵게(검정) 1곳 + 빨강 굵게(결론) 1곳으로 두 단계만 사용. 사진은 좌우 여백 없이 꽉 채움

## 사용 팁
- 잘 맞는 상품: 여러 구성품이 함께 오는 세트 (과메기·회·해산물 세트, 쌈 채소 동봉 상품, 선물 세트, 밀키트)
- 설명 문장은 사진에 실제로 보이는 구성품만 말한다. 사진에 없는 구성품을 설명에 쓰지 않는다
- 필요한 사진: 받는 그대로의 구성품을 위에서 찍은 플랫레이. 용기 크기가 비슷하게 맞춰져 있으면 정돈돼 보임. 포장 라벨이 보이면 라벨 내용은 직접 읽힌 것만 사실로 쓴다
- "완벽한 한 상", "제대로 즐기는" 같은 감성 강조어는 그대로 써도 된다 (prompt.md 준법 필터 완화 기준). 단 구성품 개수·중량은 사용자가 준 값만 쓴다
