# block_option_01

- 역할 태그: option
- 출처 형식: 상품 판매형 (수산 가공식품 세트)
- 한 줄 설명: "상품명 + 옵션안내" 제목 아래, 옵션마다 [사진 카드 → 원산지 표기 → 번호·추천 태그 붙은 옵션명 → 구성 목록]을 반복해 쌓는 옵션 안내 블록
- **사진 사용 규칙 (사용자 지정, 2026-10-13)**: 가격 옵션이 **여러 개**이면 사진 카드를 쓰지 않는다. 옵션마다 [원산지 → 번호 옵션명 → 가격 → 구성 목록]만 쌓고, 옵션 사이는 가는 구분선으로 나눈다. 가격 옵션이 1개일 때만 사진 카드를 쓴다

│  ╰──────────────────────────╯  │
│               [원산지 표기 1~3줄]│  ← 오른쪽 정렬, 작은 글씨
│                              │

## 요소와 슬롯
| 슬롯 | 요소 | 권장 글자 수 | 비고 |
|---|---|---|---|
| {상품명} | 텍스트 | 10~14자 | 작은 제목 |
| {블록제목} | 텍스트 | 4~6자 | "옵션안내" 같은 섹션명. 가장 큰 글씨 |
| {옵션사진N} | 이미지 | 약 550 x 360px | 둥근 모서리 카드 안. 해당 옵션 구성이 실제로 보이는 컷. **가격 옵션이 여러 개면 쓰지 않음** |
| {가격N} | 텍스트 1줄 | "판매가 ~~정가~~ 특가 OOO원" | 가격 정보가 있을 때만. 옵션명 아래, 특가는 포인트 컬러 굵게 |
| {구분선} | 가는 선 | — | 사진 없이 옵션이 여러 개일 때 옵션 사이에 넣음 |
| {원산지N} | 텍스트 | 1~3줄, 줄당 20자 내외 | "원산지 : 품목 - 산지" 형식. 오른쪽 정렬 |
| {번호N} | 원형 숫자 | 1자 | 검은 원 + 흰 숫자 |
| {추천태그} | 텍스트 | 2~4자 | [추천] 등. 추천 옵션 1개에만 |
| {옵션명N} | 텍스트 | 1~3줄, 줄당 14자 내외 | 중량·수량·인분 포함 |
| {구성목록N} | 대시 목록 | 항목당 15자 내외, 3~5항목 | 하위 품목은 들여쓴 줄로 나열 |

## 스타일
- 배경색 / 포인트 컬러: 흰 배경, 사진 카드는 연회색(#f3f3f3 내외) 둥근 모서리(약 16px) / 포인트 컬러 없이 검정 위주, 번호만 검은 원
- 폰트 크기 위계: 블록제목 약 40px (아주 굵게) / 상품명 약 24px / 옵션명 약 30px (굵게) / 구성목록 약 22px / 원산지 약 16px
- 여백, 정렬, 강조 방식: 제목은 가운데, 옵션명·구성목록은 왼쪽 정렬(좌우 여백 약 40px), 원산지는 오른쪽 정렬. 사진 카드 좌우 여백 약 30px. 옵션과 옵션 사이 약 60px

## 사용 팁
- 잘 맞는 상품: 중량·수량·구성별 옵션이 여러 개인 상품 (과메기 마릿수별, 과일 kg별, 세트 구성별)
- 옵션명·중량·수량·구성·원산지는 모두 사실 정보다. 사용자가 준 내용만 쓰고, 없으면 [확인 필요]로 표시한다
- 가격 옵션이 여러 개면 옵션 사진을 넣지 않는다 (사용자 지정). 구성은 앞의 detail 블록 사진과 구성 목록 글로 보여준다
- 가격 옵션이 1개라서 사진을 쓸 때는 그 옵션 구성에서 실제로 보이는 것과 구성목록이 일치해야 한다. 사진이 없으면 [사진 필요: 옵션 구성 컷]으로 표시한다
- [추천] 태그는 사용자가 정한 옵션에만 붙인다. 판매량 1위 같은 근거 없는 이유는 쓰지 않는다
- 원산지 표기는 식품 상세페이지 필수 정보이므로 블록에서 빼지 않는다
